# Cybersecurity Governance KPI Strategy

## Overview

This project demonstrates the design and implementation of an Enterprise Cybersecurity Key Performance Indicator (KPI) Strategy for a simulated organisation, **Nkanyezi Properties (Pty) Ltd**.

The KPI strategy establishes measurable performance indicators that enable management to monitor the effectiveness of cybersecurity controls, evaluate organisational security performance, and support informed governance decisions.

---

## Objectives

- Develop measurable cybersecurity KPIs.
- Monitor the effectiveness of security controls.
- Support governance and compliance reporting.
- Promote accountability through KPI ownership.
- Enable continuous improvement of the organisation's cybersecurity posture.

---

## Standards and Legislation

This strategy was developed with reference to:

- NIST Cybersecurity Framework (CSF)
- ISO/IEC 27001
- Protection of Personal Information Act (POPIA)
- Cybercrimes Act 19 of 2020 (South Africa)
