# Enterprise Cybersecurity Policy

## Overview

This project presents a professionally structured Enterprise Cybersecurity Policy developed for a simulated organisation.

The policy establishes security requirements, defines user responsibilities, and provides guidance for protecting organisational information systems against cyber threats while supporting compliance with recognised cybersecurity standards and South African legislation.

---

## Objectives

- Develop an enterprise cybersecurity policy
- Define acceptable security practices
- Protect organisational information assets
- Support regulatory compliance
- Establish clear security responsibilities

---

## Standards Referenced

- ISO/IEC 27001
- NIST Cybersecurity Framework (CSF)
- POPIA
- Cybercrimes Act 19 of 2020
