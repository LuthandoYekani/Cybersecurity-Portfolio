# Enterprise Cybersecurity Policy

## Overview

This project demonstrates the development of an Enterprise Cybersecurity Policy for a simulated organisation, **Nkanyezi Properties (Pty) Ltd**.

The policy establishes governance principles, defines security responsibilities, and outlines the minimum cybersecurity requirements necessary to protect organisational information assets, systems, and network infrastructure. It is aligned with recognised cybersecurity frameworks and South African legislation.

---

## Objectives

- Develop a comprehensive enterprise cybersecurity policy.
- Establish organisational security governance.
- Define user roles and security responsibilities.
- Promote secure use of organisational systems.
- Support compliance with recognised cybersecurity standards.

---

## Standards and Legislation

This policy was developed with reference to:

- NIST Cybersecurity Framework (CSF)
- ISO/IEC 27001
- Protection of Personal Information Act (POPIA)
- Cybercrimes Act 19 of 2020 (South Africa)
