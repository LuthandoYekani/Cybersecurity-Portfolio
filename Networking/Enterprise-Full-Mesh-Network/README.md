# Project Overview

This project demonstrates the design, implementation and verification of a secure enterprise network using Cisco Packet Tracer.

The network was designed using a four-router full mesh topology to provide redundant communication paths between four Local Area Networks (LANs). Static routing was implemented to enable end-to-end communication across the network.

The project was completed as part of my Cybersecurity Analyst practical training and focuses on enterprise networking, secure configuration and troubleshooting.
