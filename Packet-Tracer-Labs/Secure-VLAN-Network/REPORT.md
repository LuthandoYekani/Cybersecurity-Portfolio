# Enterprise VLAN Setup and Network Security

## Technical Report

---

## Project Summary

This project demonstrates the implementation of a secure enterprise network using Cisco Packet Tracer.

The network was designed to support multiple Virtual Local Area Networks (VLANs), secure switch configuration, centralized logging, secure remote management and traffic filtering using Access Control Lists (ACLs).

The implementation follows common enterprise networking practices used in production environments.
